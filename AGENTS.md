# Agents

This application is built from RAS recipes. `ras-recipes.json` records each recipe it took, the version and commit it came from, where the recipe's files live here, and every intentional difference from the recipe. Add, update, or check recipes with the `ras-recipes` skill in [ras-stack](https://github.com/richardsolomou/ras-stack/tree/main/skills/ras-recipes), and record each new intentional difference in that recipe's `notes`.

Run `pnpm check` before finishing a change.
